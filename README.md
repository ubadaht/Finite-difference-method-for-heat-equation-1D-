# Finite-difference-method-for-heat-equation-1D-

This repository solves the 1D heat equation using finite differences in space and time-marching schemes.

Implemented methods

Explicit Euler (FTCS)

Implicit Euler (BTCS)

Crank–Nicolson

Numerical approach

Centered second-order finite differences for the spatial derivative

Method of Lines formulation

Homogeneous Dirichlet boundary conditions

Exact solution used for validation
